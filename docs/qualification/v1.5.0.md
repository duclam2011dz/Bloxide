## Determinism and baseline

The GNU 16.1 Windows reference hashes remain exact. Independently exported 36 block probes across
three generator versions, three seeds and four signed/extreme coordinates match between Windows
GNU 16.2/MSVC 19.44 and Linux GNU 12.3/Clang 15.0.7 (0/36 differences in the reviewed corpus).
Each profile also verifies independent processes, reversed chunk order and threaded generation.
This finite corpus does not promise universal cross-toolchain floating-point identity.

The fixed hardware baseline uses clean commit 8a409d8, five repeats per near/LOD x overlay variant,
5 s warmup and 30 s samples after readiness. Full configuration, camera, hardware, effective
distance and per-run measurements are in PERFORMANCE.md and benchmarks/reports/.

## Limits

Linux packages are built on Ubuntu 22.04; X11/XWayland and a suitable system GL driver are required.
Native Wayland is not the standard supported path. macOS has no qualified GPU/package release.
System-provider builds are advanced, not the pinned CI route. Edits/fluid changes remain RAM-only;
far distance remains budget-adaptive; unsupported telemetry is N/A. No new gameplay, worldgen
version, material, physics tuning or LOD algorithm is included in v1.5.
