# v1.5 scope and qualification

v1.4 implements density terrain, fluids, features, adaptive surfaces and DevTools.
v1.5 changes repository quality, lifecycle, build/runtime portability, CI and distribution only.
Historical implementation sections are reference material, not additional current support claims.

Unchanged limitations: edits/fluid journals are RAM-only; effective far distance is adaptive;
vendor GPU counters are capability-dependent; macOS GPU support is not yet qualified.
No new worldgen version, block catalog, physics tuning, gameplay or LOD algorithm is introduced.

Qualification results must identify the tested commit, toolchain, OS/architecture and package.
Until gates have run, new platforms are implementation targets rather than verified support.
