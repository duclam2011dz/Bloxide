# Procedural block textures (current v1.4/v1.5 catalog)

112 material PNGs, 28 groups x four variants, 32x32 source RGBA8, generator v1.4.0,
texture seed 125. Texture seeds do not affect terrain. The original layers 0-19 are unchanged.

| Group | Base layer | Policy |
|---|---:|---|
| Grass top / Grass side / Dirt / Stone / Bedrock | 0 / 4 / 8 / 12 / 16 | Opaque |
| Iron / Gold / Diamond ore | 20 / 24 / 28 | Opaque |
| Water | 32 | Translucent |
| Oak log side / top / leaves / planks | 36 / 40 / 44 / 48 | Leaves cutout; others opaque |
| Birch log side / top / leaves / planks | 52 / 56 / 60 / 64 | Leaves cutout; others opaque |
| Pine log side / top / leaves / planks | 68 / 72 / 76 / 80 | Leaves cutout; others opaque |
| Sand / Glass / Bricks / Slate roof | 84 / 88 / 92 / 96 | Glass translucent; others opaque |
| Red flower / Yellow flower / Cobblestone | 100 / 104 / 108 | Flowers cutout; Cobblestone opaque |

Variant layer is base + 0..3. Grass bottom uses Dirt. manifest.txt is authoritative for ordering,
render policy, filenames, seed and generator version; directory enumeration is never used.
Opaque assets require alpha 255; cutout assets have alpha 0/255 and coverage-preserving mipmaps;
translucent assets require the catalog's material-specific alpha. Loader rejects missing/corrupt
PNG, wrong dimensions, non-RGBA source, non-8-bit channels or invalid alpha policy.

All assets are first-party, generated by src/TextureGenerator.cpp under the project MIT license.
No external Minecraft texture pack or bitmap is embedded. Contact/repeat sheets are derived previews,
not texture layers. Noise/warping, cellular masks, quantization and ordered dithering are procedural.
Variants share borders. Grass side is deliberately directional vertically and repeats horizontally.

World-block UVs repeat on greedy quads. Coordinate-hashed variants do not split greedy merge keys.
Opaque, cutout and depth-sorted translucent passes are separate.

Generation is explicit, never a normal-build side effect:

```text
BloxideTextureGenerator --output assets/textures --seed 125
```

Do not regenerate or modify PNGs as part of the v1.5 portability/formatting work.
